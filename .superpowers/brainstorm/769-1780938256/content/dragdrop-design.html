Design Section 3: Logo upload drag states

Three states the upload zone needs to handle. Does this feel right?

1 — Idle (unchanged)

⬆

Upload logo

PNG, JPG, WebP up to 2 MB

Click to browse. Drag a file over the zone to activate drag state.

2 — Drag-over (new)

⬇

Drop to upload

PNG, JPG, WebP up to 2 MB

Brand color border + tinted background signals "drop here".

3 — Invalid drop (new)

✕

Not an image file

PNG, JPG, or WebP only

Shown for 2s then resets to idle. No file is accepted.

Implementation notes

  • dragover → set isDragging = true, call e.preventDefault()
  • dragleave → set isDragging = false
  • drop → check file.type against ['image/png','image/jpeg','image/webp']. Valid → run existing onFileChange logic. Invalid → show error state for 2s then reset.
  • All 3 handlers attached to the existing <button> dropzone in StepBranding.vue — no new elements needed.
