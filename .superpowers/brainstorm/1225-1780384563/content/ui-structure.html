Design Section 2 — UI Structure

Pages, components, and navigation for Phase 1. Review the full layout and let me know if anything needs adjusting.

Navigation & Routing

Volunteer Scheduling
GET /dashboard/scheduling → Dashboard (overview)
Service Plans
GET /dashboard/scheduling/plans → Plans index (list)
GET /dashboard/scheduling/plans/create → Create plan form
GET /dashboard/scheduling/plans/{plan} → Plan detail — Sidebar+Panel layout
PATCH /dashboard/scheduling/plans/{plan}/publish → Publish action
Positions (library)
GET /dashboard/scheduling/positions → Position library manager
POST /dashboard/scheduling/positions → Create position
PUT /dashboard/scheduling/positions/{p} → Edit position
Assignments (API actions — no full page)
POST /dashboard/scheduling/assignments → Assign volunteer to slot
DELETE /dashboard/scheduling/assignments/{a} → Remove assignment
PATCH /dashboard/scheduling/assignments/{a}/respond → confirm / decline
My Schedule (member view)
GET /dashboard/scheduling/my-schedule → Member's upcoming assignments

Page Breakdown

📊 Schedule Dashboard
• Stat strip: Upcoming / Open slots / Pending responses
• Upcoming plans cards (next 4 weeks)
• Quick action: Create Plan button
• Recent plans with status badges
📋 Plans List
• Filter tabs: Upcoming / Past / All
• Status filter: Draft / Published / Archived
• Plan cards: title, date, dept count, fill rate
• Create Plan button (admin only)
⭐ Plan Detail — Sidebar + Panel (the core page)
LEFT SIDEBAR
• Plan title + date + status badge
• Publish / Archive buttons
• Department list nav
↳ each with filled/total count
• Add Department button
RIGHT PANEL — selected department
• Position rows with slot status dot
• Assigned volunteer avatar + name + confirmation badge
• Empty slot → "Assign" button → member picker drawer
• Add Position button (pulls from dept library)
• Remove position from plan
Assignment Drawer (slide-in panel): search members of that department → click to assign → drawer closes → slot shows assigned member
🔧 Position Library
• Grouped by department
• Create / edit / deactivate positions
• Admin only (church_admin / super_admin)
👤 My Schedule
• Member's upcoming assignments (upcoming first)
• Each card: plan title, date, position, dept
• Confirm / Decline buttons inline
• Status badge: Pending / Confirmed / Declined
• Accessible to every authenticated member
